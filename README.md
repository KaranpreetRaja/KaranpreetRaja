Projects that I've worked on:

- [**Spamino**](https://github.com/KaranpreetRaja/Spamino): A reverse TCP proxy that acts as a filtration system for spam emails. It uses a machine learning model to classify emails and mark them if they are spam/phishin emails or not. It also has a web interface that allows users to view the emails that have been marked as spam.
- [**Eventure**](): A mobile application built using React Native and Firebase that allows users to create and manage events. It also has a point-based system that rewards users for attending events.

- [**Fake News Detection**](https://github.com/KaranpreetRaja/Detecting-Fake-News-AI): A machine learning model that uses the DistilBERT transformer model to classify news articles as fake or real. The project utalizes k-fold cross validation with a logistic regression model to achieve an accuracy of 96%.

- [**Centurion**](): A custom Heavy JDK that supplies its users with a large set of java tools and libraries.
